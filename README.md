# Entornos-de-Desarrollo-Actividad-1.-Alvaro-Cortes-Godino

Explica como desarrollarías una pequeña aplicacion o juego

1. Problema, plataforma y lenguaje:
Haré un pequeño juego de adivinar un número en el que el ordenador tiene un número y el jugador que este participando tratará de adivinarlo en un numero especifico de intentos, para que sea mas intuitivo habrá vidas y logros/medallas que se conseguirán al cumplir ciertos requisitos, como por ejemplo acertar 5 seguidas, pasar niveles en cierto tiempo, etc... También al avanzar de niveles se desbloquean nuevas zonas y se podrá cambiar de personaje.  Usaré de plataforma un ordenador y de lenguaje Visual Studio Code

2. Algoritmo o paradigma:
El ordenador elige un número y el jugador intenta adivinarlo en una cantidad de intentos, si acierta conseguirá logros, cambiará de zona donde se juega o podrá cambiar de personaje. Compilación Imperativa (pasos y estado)

3. Como se ejecuta el código:
Guardaré el código con .html y lo ejecutaré en Visual Studio Code ya que al haber varios apartados (jugadores, vidas, logros, etc...) es mas adecuado para controlar

4. Commit, push y GitHub:
Haré un commit para guardar los cambios, un push para subirlos a GitHub y comprobaré que el archivo está correctamente subido
